Your AI coding agent should see the names of your secrets, never the values.

AI coding tools read your project files to help you — including .env files full of API keys and passwords. VaultShield moves those values into the macOS Keychain and leaves a harmless placeholder behind, so the agent still sees that a key exists and what it is called, but not the secret itself.

Three steps

  1. Install. Paste one command in Terminal. It sets up a private, isolated copy of VaultShield and nothing else on your system.
  2. Secure a project. In your project folder, run vaultshield secure. It shows what it found, asks before changing anything, and tucks the values into the Keychain.
  3. Ask your agent as usual. Point your AI coding tool at the project. It sees API_KEY=vs_protected, not your real key.

Install

macOS, one line in Terminal:

curl -fsSL http://localhost:8080/install.sh | sh

It finds a Python 3.11+, makes a private environment just for VaultShield, and adds a vaultshield command. It installs no system software and never edits your shell startup files. Remove it later with curl -fsSL http://localhost:8080/install.sh | sh -s -- --uninstall.

What it protects, and what it does not

  • ✓ The value of every variable VaultShield moves out of a .env file. It lives in the Keychain; the file holds vs_protected.
  • ✓ The agent can still read variable names, so it can reason about your project without seeing a single secret.
  • ✓ You can undo it any time with vaultshield unprotect, which puts the real values back.

Honest about the limits:

  • ! VaultShield protects the files it moves. A value you copied into a comment, another file, git history, or your shell history is not touched.
  • ! A determined program running as you can still try indirect tricks (reading the Keychain through other tools, or encoding a value so a simple filter misses it). VaultShield raises the bar; it is not a sandbox.
  • ! Only results that were actually measured are claimed below. Nothing here is a guarantee.

Measured so far

  • ✓ Placeholders held in the Antigravity CLI and App: an agent that got past the rules read the placeholder, not the secret.
  • ✓ The command hook blocked printenv live in Antigravity.
  • ○ Claude Code, Kiro and Codex backstops are built from docs, not yet live-tested.
