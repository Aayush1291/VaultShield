VaultShield
macOS only · for AI coding agents

Let AI agents read your code, not your secrets.

AI coding tools read your project files to help you — including .env files full of API keys. VaultShield moves those values into the macOS Keychain and leaves a harmless placeholder, so the agent still sees that a key exists and what it is called, never the secret itself.

curl -fsSL http://localhost:8080/install.sh | sh

One line in Terminal. It installs a private, isolated copy and nothing else — no system software, no edits to your shell startup files.

$ vaultshield secure
Moved 1 value to the Keychain, left a placeholder.
# what your agent now reads:
STRIPE_KEY=vs_protected

Three steps

  1. Install

    Paste the one command above in Terminal. It sets up a private, isolated copy of VaultShield and nothing else on your system.

  2. Secure a project

    In your project folder, run vaultshield secure. It shows what it found, asks before changing anything, and tucks the values into the Keychain.

  3. Ask your agent as usual

    Point your AI coding tool at the project. It sees API_KEY=vs_protected, not your real key.

What it protects, and what it does not

  • ✓ The value of every variable VaultShield moves out of a .env file. It lives in the Keychain; the file holds vs_protected.
  • ✓ The agent can still read variable names, so it can reason about your project without seeing a single secret.
  • ✓ You can undo it any time with vaultshield unprotect, which puts the real values back.

Honest about the limits:

  • ! VaultShield protects the files it moves. A value you copied into a comment, another file, git history, or your shell history is not touched.
  • ! A determined program running as you can still try indirect tricks (reading the Keychain through other tools, or encoding a value so a simple filter misses it). VaultShield raises the bar; it is not a sandbox.
  • ! Only results that were actually measured are claimed below. Nothing here is a guarantee.

FAQ

Does the AI agent ever see my real keys?
No — not for the values VaultShield moved. It reads the variable names and the placeholder vs_protected. The real value is in the macOS Keychain.
Is this a sandbox?
No. It is not a sandbox. It moves secret values out of the files an agent reads and raises the bar against casual exposure, but a determined program running as you can still try indirect tricks. Use the sandboxed vaultshield run for stronger isolation.
Which platforms are supported?
macOS only, for now — it relies on the macOS Keychain and needs Python 3.11+.
How do I remove it?
Re-run the install command with -s -- --uninstall. It removes the private environment and the vaultshield command and leaves your secrets in place.
